### 38.4.2 Access port register map

These registers are not on the CPU memory bus. They are only accessed through SW-DP
debug interface.

The access port address is 8-bit wide, defined by DP_SELECT.APBANKSEL[3:0] field and
by the SW-DP packet request A[3:2] field. The two least significant bits are 00.

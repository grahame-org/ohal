### 5.4.17 AHB peripheral clock enable in Sleep mode register (RCC_AHBSMENR)

Address offset: 0x68

Reset value: 0x0105 1303

This register can individually program which AHB peripheral clocks are disabled (bit
cleared) upon the device entering Sleep mode. When a bit of this register is set (enable), the
corresponding peripheral clock is supplied in Sleep mode according to the setting of the
RCC_AHBENR register.

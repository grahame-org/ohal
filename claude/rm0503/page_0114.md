#### Peripheral clock gating

In Run mode, the HCLK and PCLK for individual peripherals and memories can be stopped
at any time to reduce the power consumption.

To further reduce the power consumption in Sleep and Stop modes, the peripheral clocks
can be disabled prior to executing the WFI or WFE instructions.

The peripheral clock gating is controlled by the RCC_AHBxENR and RCC_APBxENR
registers.

Disabling the peripherals clocks in Sleep and Stop modes can be performed automatically
by resetting the corresponding bit in the RCC_AHBxSMENR and RCC_APBxSMENR
registers.

#### Debug mode

By default, the debug connection is lost if the application puts the MCU in Stop 0, Stop 1,
Stop 2, Standby or Shutdown mode while the debug features are used. This is due to the
fact that the Cortex®-M0+ core is no longer clocked.

However, by setting some configuration bits in the DBGMCU*CR register, the software can
be debugged even when using the low-power modes extensively. For more details, refer to
\_Section 38.2.6: Debug in low-power modes\*\*.*

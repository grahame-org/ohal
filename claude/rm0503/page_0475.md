Unlike charge transfer acquisition (where the threshold is fixed = VIH), here the threshold is
programmable. The sampling capacitor is internally redirected to the comparator input in
order to offer a programmable voltage threshold value VCOMP based on VREFINT. The
possible configurations are about 0.3, 0.6, 0.9 or 1.2 V (corresponding to 1/4VREFINT,
1/2VREFINT, 3/4VREFINT or VREFINT).

VREFINT is the bandgap voltage (~1.2 V).

By reducing the voltage threshold, the acquisition time is shortened which in turn reduces
the power consumption.

The selection of the threshold value is a compromise between sensor acquisition time (the
lowest the threshold the best) and sensor sensitivity (the highest the threshold the best).

The SYSCFG_TSCCR register should be set appropriately in order to configure the MUX
allowing the use of the comparator mode instead of the usual TSC mode (see device
reference manual).

### 27.3 LPTIM implementation

The table below describes LPTIM implementation on STM32U0 series devices. The full set
of features is implemented in LPTIM1 and LPTIM3. LPTIM2 supports a smaller set of
features.

**Table 145. STM32U0 series LPTIM features**

| LPTIM modes/features(1) | LPTIM1 | LPTIM2 | LPTIM3(2) |
| ----------------------- | ------ | ------ | --------- |
| Encoder mode            | X      | X      | X         |
| PWM mode                | X      | X      | X         |
| Input Capture           | X      | X      | X         |
| Number of channels      | 4      | 2      | 4         |
| Number of DMA requests  | 5      | 3      | 5         |
| Wake-up in Stop mode    | X      | X      | X         |

1. X = supported.
2. LPTIM3 is only available on STM32U073/U083 devices.

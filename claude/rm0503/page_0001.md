## STM32U0 series advanced Arm®-based 32-bit MCUs

### Introduction

This reference manual targets application developers. It provides complete information on
how to use the STM32U0 series microcontroller memory and peripherals.

The STM32U0 series are microcontroller lines with different packages and peripherals.

Refer to the corresponding data briefs for ordering information, mechanical and electrical
device characteristics.

For information on the Arm® Cortex®-M0+ core, refer to the Cortex®-M0+ _Technical Reference Manual_.

The STM32U0 series microcontrollers include ST state-of-the-art patented technology.

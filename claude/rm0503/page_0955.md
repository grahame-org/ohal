## 32.5 TAMP interrupts

#### Table 184. Interrupt requests

| Interrupt acronym | Interrupt event      | Event flag(1) | Enable control bit | Interrupt clear method | Exit from low-power modes |
| ----------------- | -------------------- | ------------- | ------------------ | ---------------------- | ------------------------- |
| TAMP              | Tamper x(2)          | TAMPxF        | TAMPxIE            | Write 1 in CTAMPxF     | Yes(3)                    |
|                   | Internal tamper y(2) | ITAMPyF       | ITAMPyIE           | Write 1 in CITAMPyF    | Yes(3)                    |

1. The event flags are in the TAMP_SR register.
2. The number of tampers and internal tampers events depend on products.
3. Refer to _Table 182: Effect of low-power modes on TAMP_ for more details about available features in the
   low-power modes.

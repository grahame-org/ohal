### 21.3.2 RNG internal signals

_Table 112_ describes a list of useful-to-know internal signals available at the RNG level, not
at the STM32 product level (on pads).

#### Table 112. RNG internal input/output signals

| Signal name   | Signal type    | Description                                                                                                                                                                                                                              |
| ------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| rng it        | Digital output | RNG global interrupt request                                                                                                                                                                                                             |
| rng hclk      | Digital input  | AHB clock                                                                                                                                                                                                                                |
| rng clk       | Digital input  | RNG dedicated clock, asynchronous to rng hclk                                                                                                                                                                                            |
| rng itamp out | digital output | RNG internal tamper event signal to TAMP (XORed), triggered when an unexpected hardware fault occurs. When this signal is triggered, RNG stops delivering random samples, requiring a reset and a new initialization to be usable again. |

### 21.3.3 Random number generation

The true random number generator (RNG) delivers truly random data through its AHB
interface at deterministic intervals.

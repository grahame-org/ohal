_Note:_
_Bits 6 and 4 of this register can be written in initialization mode only (RTC_ICSR/INITF = 1)._

_WUT = wake-up unit counter value. WUT = (0x0000 to 0xFFFF) + 0x10000 added when_
_WUCKSEL[2:1 = 11]._

_Bits 2 to 0 of this register can be written only when RTC_CR WUTE bit = 0 and RTC_ICSR_
_WUTWF bit = 1._

_It is recommended not to change the hour during the calendar hour increment as it may_
_mask the incrementation of the calendar hour._

_ADD1H and SUB1H changes are effective in the next second._

### 31.6.9 RTC calibration register (RTC_CALR)

This register is write protected. The write access procedure is described in _RTC register_
_write protection on page 914_.

Address offset: 0x28

Backup domain reset value: 0x0000 0000

System reset: not affected

_Note: LCDCLK is the same as RTCCLK. Refer to the RTC/LCD clock description in the RCC section._

The frequency generator allows the user to achieve various LCD frame rates starting from
an LCD input clock frequency (LCDCLK), which can vary from 32 kHz up to 1 MHz.

Three different clock sources can be used to provide the LCD clock (LCDCLK/RTCCLK):

- 32 kHz low-speed external RC (LSE) (refer to the RCC section)
- 32 kHz low-speed internal RC (LSI)
- high-speed external (HSE) divided by 32

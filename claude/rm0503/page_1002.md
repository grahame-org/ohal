## 33.5 I2C in low-power modes

#### Table 196. Effect of low-power modes to I2C

| Mode       | Description                                                                                                                                                                                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Sleep      | No effect. I2C interrupts cause the device to exit the Sleep mode.                                                                                                                                                                                                                         |
| Stop(1)(2) | The contents of I2C registers are kept. – WUPEN = 1 and I2C is clocked by an internal oscillator (HSI16). The address recognition is functional. The I2C address match condition causes the device to exit the Stop mode. – WUPEN = 0: the I2C must be disabled before entering Stop mode. |
| Standby    | The I2C peripheral is powered down. It must be reinitialized after exiting Standby mode.                                                                                                                                                                                                   |

1. Refer to _Section 33.3: I2C implementation_ for information about the Stop modes supported by each
   instance. If the wake-up from a specific stop mode is not supported, the instance must be disabled before
   entering that specific Stop mode.
2. Only I2C3 supports wake-up from Stop 2 mode. The other I2C instances must be disabled before entering
   Stop 2 mode.

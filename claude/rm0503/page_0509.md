#### Counter (CTR) mode

**Figure 98. CTR encryption and decryption principle**

The CTR mode uses the AES core to generate a key stream. The keys are then XOR-ed
with the plaintext to obtain the ciphertext as specified in NIST _Special Publication 800-38A, Recommendation for Block Cipher Modes of Operation_.

_Note: Unlike with ECB and CBC modes, no key scheduling is required for the CTR decryption, since in this chaining scheme the AES core is always used in encryption mode for producing the key stream, or counter blocks._

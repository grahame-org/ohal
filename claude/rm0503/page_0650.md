#### Bits 27:24 TI4SEL[3:0]: selects TI4[0] to TI4[15] input

0000: TIM1_CH3 input

#### Bits 11:8 TI2SEL[3:0]: selects TI2[0] to TI2[15] input
0000: TIM1_CH2 input
0001: COMP2 output
Others: Reserved

#### Bits 7:4 Reserved, must be kept at reset value.

#### Bits 3:0 TI1SEL[3:0]: selects TI1[0] to TI1[15] input
0000: TIM1_CH1 input
0001: COMP1 output
Others: Reserved

### 25.3.5 Debug mode

When the microcontroller enters the debug mode (Cortex®-M0+ core - halted), the TIMx
counter either continues to work normally or stops, depending on the DBG*TIMx_STOP
configuration bit in the DBG module. For more details, refer to \_Section 38.9: Microcontroller*
_debug unit (DBGMCU)_.

#### Bits 13:8 PUy: Port D pull-up bit y (y = 13 to 8)

When set, this bit activates the pull-up on PD[y] when APC bit is set in PWR_CR3 register. If
the corresponding PDy bit is also set, the pull-up is not activated and the pull-down is
activated instead with highest priority.

#### Bit 7 Reserved, must be kept at reset value.

#### Bits 6:0 PUy: Port D pull-up bit y (y = 6 to 0)

When set, this bit activates the pull-up on PD[y] when APC bit is set in PWR_CR3 register. If
the corresponding PDy bit is also set, the pull-up is not activated and the pull-down is activated
instead with highest priority.

### 4.4.15 Power Port D pull-down control register (PWR_PDCRD)

Address offset: 0x3C

Reset value: 0x0000 0000

This register is neither reset when exiting Standby or Shutdown mode, nor by the PWRRST
bit in the RCC_APB1RSTR1 register.

Access: Additional APB cycles are needed to access this register vs. a standard APB
access (3 for a write and 2 for a read).

### 4.4.16 Power Port E pull-up control register (PWR_PUCRE)

Address offset: 0x40

Reset value: 0x0000 0000

This register is neither reset when exiting Standby or Shutdown mode, nor by the PWRRST
bit in the RCC_APB1RSTR1 register.

Access: Additional APB cycles are needed to access this register vs. a standard APB
access (3 for a write and 2 for a read).

#### Bits 31:6 Reserved, must be kept at reset value.

#### Bits 5:0 EMx: CPU wake-up with event generation mask on line x, (x = 37 to 32)

Setting/clearing each bit unmasks/masks the CPU wake-up with event generation on the
corresponding line.
0: wake-up with event generation masked
1: wake-up with event generation unmasked
Bit IM36 is available only on STM32U0x3xx devices, it is reserved on STM32U031xx
devices.

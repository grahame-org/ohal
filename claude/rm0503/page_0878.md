### 27.7.18 LPTIM compare register 4 (LPTIM_CCR4)

Address offset: 0x03C

Reset value: 0x0000 0000

#### Bits 31:16 Reserved, must be kept at reset value.

#### Bits 15:0 CCR4[15:0]: Capture/compare 4 value

If channel CC4 is configured as output:
CCR4 is the value to be loaded in the capture/compare 4 register.
Depending on the PRELOAD option, the CCR4 register is immediately updated if the PRELOAD bit
is reset and updated at next LPTIM update event if PREOAD bit is reset.
The capture/compare register 4 contains the value to be compared to the counter LPTIM_CNT and
signaled on OC4 output.
If channel CC4 is configured as input:
CCR4 becomes read-only, it contains the counter value transferred by the last input capture 4 event.
The LPTIM_CCR4 register is read-only and cannot be programmed.

#### Caution:

The LPTIM_CCR4 register must only be modified when the LPTIM is enabled (ENABLE bit
set to 1).

_Note:_
If the LPTIM implements less than 4 channels this register is reserved. Refer to
_Section 27.3: LPTIM implementation_.

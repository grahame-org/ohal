## 20.3 TSC implementation

### Table 105. TSC implementation

| TSC features                | STM32U031xx | STM32U0x3xx |
| --------------------------- | ----------- | ----------- |
| Number of analog I/O groups | 6(1)        | 7           |
| Number of channels          | 18          | 21          |

1. Only Gx, x = 1 to 6 applies for this category of devices. G7 related information does not apply and

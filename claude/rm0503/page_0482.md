### 20.7.5 TSC I/O hysteresis control register (TSC_IOHCR)

Address offset: 0x10

Reset value: 0xFFFF FFFF

| Res. | Res. | Res. | Res. | G7 IO4 \* | G7 IO3 | G7 IO2 \* | G7 IO1 \* | G6 IO4 | G6 IO3 \* | G6 IO2 \* | G6 IO1 | G5 IO4 \* | G5 IO3 \* | G5 IO2 | G5 IO1 \* |

| rw        | rw     | rw        | rw        | rw     | rw        | rw        | rw     | rw        | rw        | rw     | rw        | rw        | rw     | rw        | rw     |

#### Bits 31:28 Reserved, must be kept at reset value.

#### Bits 27:0 Gx_IOy: Gx_IOy Schmitt trigger hysteresis mode

These bits are set and cleared by software to enable/disable the Gx*IOy Schmitt trigger
hysteresis.
0: Gx_IOy Schmitt trigger hysteresis disabled
1: Gx_IOy Schmitt trigger hysteresis enabled
\_Note:* \_These bits control the I/O Schmitt trigger hysteresis whatever the I/O control mode is\_
_(even if controlled by standard GPIO registers)._

Reset value: 0x0000 0000

#### Bits 31:28 Reserved, must be kept at reset value.

#### Bits 27:0 Gx_IOy: Gx_IOy analog switch enable

These bits are set and cleared by software to enable/disable the Gx*IOy analog switch.
0: Gx_IOy analog switch disabled (opened)
1: Gx_IOy analog switch enabled (closed)
\_Note:* \_These bits control the I/O analog switch whatever the I/O control mode is (even if controlled by standard GPIO registers).\_

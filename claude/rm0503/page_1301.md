#### Bit 16 REGWNR: Transfer direction.
0: read from register into SCS_DCRDR
1: write contents of SCS_DCRDR to register

#### Bits 15:5 Reserved, must be kept at reset value.

#### Bits 4:0 REGSEL[4:0]: Register select.
This field specifies the Cortex®-M0+ core register or special purpose register targeted for the
transfer.
0b00000 - 0b01100: R{v}
0b01101: Current SP
0b01110: LR
0b01111: Debug return address
0b10000: xPSR
0b10001: MSP, main stack pointer
0b10010: PSP, process stack pointer
0b10100: bits 31:24 - CONTROL; bits 23:8 - reserved; bits 7:0 PRIMASK
Others: reserved, must not be used

#### Bits 31:0 DBGTMP[31:0]: Temporary data register for reading and writing core registers.
Data written by the debugger to this register are transferred into the register specified in the
DCRSR.REGSEL field, when the latter is written with REGWNR bit set.
When DCRCR.REGSEL is written with REGWNR bit cleared, the contents of the specified
register are transferred into this register and can be read by the debugger.
In both cases the DHSCR.S_REGRDY bit indicates when the transfer is complete.

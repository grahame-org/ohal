#### Bit 23 UEDE: Update event DMA request enable

0: UE DMA request disabled. Writing '0' to the UEDE bit resets the associated ue*dma_req signal.
1: UE DMA request enabled
\_Note:* _If LPTIM does not implement at least 1 channel this bit is reserved. Refer to **Section 27.3**._
